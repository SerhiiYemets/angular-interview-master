# Angular Learning Project

**A hands-on Angular 22 learning project focused on components, data binding, directives, control flow, pipes, and component communication.**

This repository contains practical exercises and examples created while studying Angular as part of my ongoing Full-Stack development education.

## 🇬🇧 English

### About the Project

This project is a personal learning environment where I explore Angular concepts through practical examples.

The goal is to strengthen my understanding of Angular, TypeScript, component-based architecture, and modern frontend development.

### Technologies

- Angular 22
- TypeScript
- HTML5
- SCSS
- Angular CLI
- Git & GitHub

### Topics Covered

**Components and Data Binding**
- Creating and using Angular components
- Interpolation (`{{ }}`)
- Property binding
- Class and style binding
- Event binding
- Two-way data binding with `ngModel`

**Component Communication**
- Parent-to-child communication using `@Input()`
- Child-to-parent communication using `@Output()` and `EventEmitter`

**Directives**
- `ngClass` and `ngStyle`
- Creating a custom `Highlight` directive
- Handling DOM events using `@HostListener`

**Built-in Control Flow**
- Conditional rendering with `@if` and `@else`
- List rendering with `@for` and `@empty`
- Conditional selection with `@switch`, `@case`, and `@default`

**Pipes**
- Built-in pipes: `date`, `uppercase`, `lowercase`, `currency`, `number`, `percent`, and `slice`
- Creating a custom `truncate` pipe
- Implementing the `PipeTransform` interface

### Getting Started

Clone the repository:

```bash
git clone https://github.com/SerhiiYemets/angular-interview-master.git
cd angular-interview-master
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npx ng serve --open
```

The application will be available at `http://localhost:4200/`.

**Development environment note:** On macOS Monterey, this project has also been run using Node.js 22.23.3 and the following command to use the JavaScript Sass implementation:

```bash
NG_BUILD_SASS_EMBEDDED=false npx ng serve --open
```
